# فونت IranSans (لایسنس‌دار)

فونت **IranSans** تجاری/لایسنس‌دار است و CDN عمومی مطمئنی ندارد. به‌صورت پیش‌فرض
این پروژه با **وزیرمتن (Vazirmatn)** — معادل متن‌باز و تقریباً یکسان با IranSans —
نمایش داده می‌شود که از گوگل‌فونت لود می‌شود و همیشه کار می‌کند.

## برای استفاده از IranSans واقعی:

۱) فایل‌های وب‌فونت IranSansX را از سایت رسمی تهیه کنید (مثلاً از
[fontiran.com](https://fontiran.com)) — فرمت **woff2**.

۲) دو فایل زیر را دقیقاً با همین نام در همین پوشه (`static/fonts/`) قرار دهید:
```
static/fonts/IRANSansX-Regular.woff2
static/fonts/IRANSansX-Bold.woff2
```

۳) اپ را دوباره اجرا کنید. چون `enableStaticServing` روشن است و در `app.py`
یک `@font-face` برای `IRANSansX` تعریف شده، فونت به‌صورت خودکار جایگزین وزیرمتن می‌شود.

> اگر نام فایل‌ها فرق دارد، فقط مسیرهای `url(...)` داخل بلوک `@font-face` در `app.py`
> را مطابق نام فایل‌های خودتان اصلاح کنید.
